# Trade历史订单入口融入交易工作区

## Goal
让手机端现货Trade页历史订单按钮更沉浸，融入持仓标签栏。

## Requirements
- 仅优化现货交易页历史订单入口；去掉常驻方块底色、边框和阴影。
- 保留右侧位置，以低强调单色历史图标呈现，悬停/按下有轻微反馈。
- 保持44×44触控区域、键盘焦点、中英文可访问名称及低动态偏好。
- 保留现有登录校验、交易上下文和历史订单跳转；不改变合约布局或其他按钮。

## Acceptance Criteria
- [x] 默认外观与交易背景融合，图标居中且可识别。
- [x] 320/390/448px、明暗主题无溢出，触控区域不缩小。
- [x] 鼠标/触控/键盘反馈可用，历史订单导航保持正确。
- [x] 现有定向回归和Mobile发布门禁执行并记录。

## Implementation Plan
1. 查看真实Trade页与当前样式，确定局部调整。
2. 在已有TradeView中添加明确按钮类并调整状态样式。
3. 浏览器验收、现有回归/发布门禁、更新规范与进度并本地提交。

## Technical Notes
- `mobile/src/views/TradeView.vue` 的spot-account-tabs末尾按钮为本次目标。
- 使用项目已有Lucide图标、主题变量与移动导航合同，不新增依赖。
- 用户“更加沉浸”按降低常驻按钮表面强调处理；范围由相邻手机端任务及Trade路由推定。
- 已加载trellis-before-dev/check及mobile相关规范；应用redesign-existing-projects的局部改进原则。
- 低影响视觉调整不新增机械源码测试，运行现有回归并以真实浏览器验证交互和布局。

## Out of Scope
PC、合约布局、订单数据/接口、交易/下单规则、推送与部署。
