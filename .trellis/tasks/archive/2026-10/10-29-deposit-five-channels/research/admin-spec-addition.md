

### Five-provider deposit setup catalog

1. **Scope:** each supported network exposes at least five distinct selectable provider choices when paired with the current public catalog. This is configuration coverage, not five configured, healthy, anonymous or free sources.
2. **Signatures:** `NodePreset.account` holds provider identity, plan label, signup, setup, interval and `credential: url-key | tron-header | endpoint`; `legacy` retains prior single-node editor choices. `providerChoiceCount(network, publicPresets)` excludes testing-only public profiles and aliases such as TronGrid public/account. These fields are browser-local.
3. **Contracts:** continue emitting the existing `SaveScannerProvider` DTO. Explicitly label paid Ethereum trace and trial/plan-dependent access. Selecting a template creates fresh key drafts with null IDs, never inherits old secrets, and sets a sticky `replacementEndpoint` requirement. Full dashboard URLs start blank; retain this requirement even when the template picker is cleared. Unchanged persisted channels still keep blank-secret preservation. TronGrid account mode requires its own key even though its base URL has no placeholder.
4. **Validation matrix:** missing new endpoint, unresolved YOUR_API_KEY/encoded/case-variant markers or enabled required key blocks save; only literal `{API_KEY}` with an independent key is accepted as a runtime placeholder; full endpoint with no extra key emits `api_key:null`; URL-key templates retain literal `{API_KEY}` plus separate key; template changes/409 retain only the new draft and reason. Selecting an anonymous profile resets account-only requirements and follows existing credential clearing.
5. **Cases:** good: add a Google Cloud/Chainstack URL from the operator console with a fresh anonymous slot, leaving the original channel intact. Base: blank-save an unchanged saved channel. Bad: rename an old channel with a new template while retaining its hidden endpoint, or count multiple keys as distinct providers.
6. **Tests:** each account template must exercise network-specific selection, new credential requirements, correct payload, no old key ID and no local metadata leakage. Verify all-five distinct counts, alias exclusion, paid labels, legacy editor parity and blank dashboard replacement. Browser checks cover desktop catalog, 320px save and 390px conflict/discard.
7. **Wrong vs correct:** wrong: ship a guessed project/region URL or mark documented access healthy. Correct: link the official console, require the exact endpoint/credentials and wait for the server's complete scan status. Public and account documentation never proves production uptime.
