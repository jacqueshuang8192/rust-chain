# 管理员代理管理界面优化

## Goal
提高管理员在代理列表中查找、识别层级和管理账号的效率，沿用现有后台视觉体系。

## Confirmed direction
用户选择“紧凑高效”：保留后台风格，精简列表、增加搜索筛选、整理详情和操作。

## Requirements
- 仅优化 `web` 管理员代理管理页；保留现有 API、权限、确认原因和充值授权语义。
- 列表按代理身份、层级关系、团队规模、状态、后台账号和操作归并展示，保留可调整列宽和表内横向滚动。
- 复用 FilterBar，支持关键词（编号、邮箱、后台账号、代理/用户 ID）、状态及层级组合查询和重置，显示匹配数量。
- 将行内密码输入及状态操作移入详情面板；资料、团队用户及管理操作分区，保留原始数据折叠与转移用户入口。
- 创建代理使用侧栏分组表单，保留最多三级及上级候选规则、必填校验与二次确认；关闭再开保留草稿，成功后清空并刷新列表。
- 加载、失败、空数据、只读权限及窄屏清晰可用；不展示误导性团队汇总。

## Acceptance Criteria
- [x] 列表六个业务分组以内，不再有常驻密码输入。
- [x] 查询提交后才应用；组合筛选、无结果与重置正确，分页归一。
- [x] 创建、状态变更、密码重置、归属转移与充值授权入口可用，接口及权限不变。
- [x] 详情切换/关闭不显示迟到数据，写操作失败保留确认内容。
- [x] 桌面和窄屏无页面级横向溢出，SideSheet、筛选和按钮可操作。
- [x] 定向测试、Web 类型/lint/构建和规定门禁运行，结果及限制记录到 PROGRESS。

## Plan
1. 核对页面、共享组件与规范，记录实施方案。
2. 优化列表、筛选、创建表单和详情布局。
3. 验证行为与浏览器布局，更新规范及交付记录。

## Out of Scope
后端、数据库、代理业务规则、全局导航/主题、其他页面、部署与推送。
