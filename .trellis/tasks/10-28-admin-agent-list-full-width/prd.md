# 代理列表占满内容区宽度

## Goal
管理员代理管理页的代理列表占后台内容区的100%宽度，保留正常页面内边距。

## Requirements
- 仅调整代理管理页的宽度约束，不影响其他后台页面。
- 列表卡片与表格随可用内容区自适应，宽屏不受通用1560px页面上限限制。
- 保留现有筛选、分页、可调整列宽和窄屏表内横向滚动。
- 保留工作区已有代理管理界面改动，不改接口、权限或管理操作。

## Acceptance Criteria
- [x] 1920/2560宽屏页面宽度与父内容区相等，列表填满扣除页面内边距后的空间。
- [x] 1728/1280/390/320没有页面级横向溢出，列表内滚动和操作可用。
- [x] 现有定向回归及Web门禁执行，浏览器检查记录到PROGRESS。

## Plan
1. 浏览器复现，确认限制来源。
2. 在代理管理页局部解除宽度上限。
3. 定向回归、浏览器和门禁验证，更新规范/进度并交付。

## Technical Notes
- 当前工作区已有未提交的10-26代理管理重构，本任务仅叠加布局修正。
- `.exchange-page`通用规则为`width: min(100%, 1560px)`。
- `.admin-resource-shell`和DataTable外层已经使用100%宽度。
- 低影响CSS修正不新增镜像源码测试，使用真实组件浏览器几何验证。

## Out of Scope
其他页面、后端、业务规则、自动推送和部署。
