# Tron 至少五家免费充值监听渠道

## Goal
核查至少五家不同服务商的持续免费 Tron 主网访问，并将符合现有完整到账扫描要求的免费选项接入后台。用户已接受免费账号与自有 API Key；本轮免费目标不包含限时试用或仅付费服务。

## Requirements
- 优先官方免费套餐，标明免费额度、速率、注册及原生 HTTP 接口限制。
- 至少五家独立服务商；同一家多个 Key、URL、测试网不重复计数。
- 完整区块、整块交易回执和 TRC-20 精度读取必须兼容现有扫描器，不能用仅余额/浏览器记录代替。
- 保持主备自动切换，保留既有配置和真实冷却，不修改账务规则。
- 账号模板须填写用户自己的凭据；不购买或注册账号、不使用历史密钥、不访问生产。

## Acceptance Criteria
- [x] 官方来源确认至少五家持续免费且支持所需原生 HTTP 方法；无法确认不凑数。
- [x] 后台可选择合格免费渠道并看到明确限制；付费/试用不计入免费数量。
- [x] 配置/凭据保存测试、类型及 lint 通过；必要的实组件验证完成。
- [x] 研究结论、验证边界和进度落盘，既有无关改动保留。

## Technical Approach
沿用前端账号模板，优先最小范围接入；只有免 Key 且完整样本验证成功才考虑公开默认项。新增 PublicNode 固定公共目录身份，需同版后端与后台；不修改扫描器、迁移或 DTO。

## Expansion / Decision
未来套餐变化由官方链接和核查日期支持复查；公共接口与账户入口不重复计数。失败保持现有冷却和游标。扩展后台额度管理、购买账户、跨网络重构不在本轮范围。用户已明确需求和免费账号偏好，不重复询问。

## Open Questions
无：沿用已确认免费账号与 API Key 偏好，官方来源及 PublicNode 样本已核查。

## Out of Scope
其他网络、代理管理、生产部署、付费开通、降级到账证据规则。
