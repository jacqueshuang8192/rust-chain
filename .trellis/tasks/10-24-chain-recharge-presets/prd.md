# Ethereum / TRC20 / Solana 主网充值预设

## Goal

参考 GMWalletApp/epusdt 的配置，为后台提供可选择的节点与币种预设，减少手填合约和精度的错误。

## Requirements

- 用户已选择后台提供主网预设，选中后填入节点/合约/精度，确认保存后生效，不自动初始化数据库。
- 覆盖 Ethereum ETH/USDT/USDC、Tron USDT TRC20、Solana SOL/USDT/USDC；仅使用核对过的官方主网身份。
- 保留手动配置及后续币种扩展；已有映射不可变身份、平台目录/权限、版本、操作原因和未保存草稿保护保持。
- 节点模板明确是否需要 API key、是否满足当前扫描器的完整区块/trace/finalized 能力；不将占位密钥当有效配置提交。
- 不填用户收款地址，不自动保存、不自动开启新单、不修改现有节点/币种配置。

## Acceptance Criteria

- [x] 三网络的节点/资产预设可选、可预览并填入编辑草稿；ETH/18、SOL/9、稳定币/6正确。
- [x] 手动配置、取消、原版本保存和权限回归通过；已有映射不被预设改写。
- [x] 预设来源/节点限制/使用步骤可查，相关测试、类型、lint、构建和浏览器验证通过；既有包体门槛超限单独记录。

## Out of Scope

修改监听协议、生产部署、实链转账、创建平台资产、生成私钥或收款地址、自动推送。
