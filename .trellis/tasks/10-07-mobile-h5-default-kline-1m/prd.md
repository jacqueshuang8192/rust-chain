# 手机端 H5 默认 K 线周期改为 1m

## 目标

手机端 H5 首次进入行情列表、行情详情和交易页时，所有默认请求的 K 线周期统一使用 `1m`。

## 范围

- 行情列表的迷你 K 线从 `15m` 改为共享默认周期 `DEFAULT_MARKET_KLINE_INTERVAL`。
- 保留用户在行情详情和交易页主动切换周期的能力。
- 补充源码回归断言，防止默认周期再次回退到固定的 `15m`。

## 验收标准

- 行情列表默认迷你 K 线请求使用 `1m`。
- 交互式行情详情、交易页和 API 默认周期继续使用 `1m`。
- 相关 Mobile 测试、类型检查和 diff 检查通过。
