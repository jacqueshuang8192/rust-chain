# 代理固定唯一邀请码

## 目标

每个代理只拥有一条固定的邀请码。重复调用代理后台邀请码接口时，返回已有邀请码，不再生成新码。

## 范围

- 后端创建接口改为幂等初始化：已有代理邀请码直接返回，没有时才生成。
- 用户端关联代理邀请码读取不再因停用旧码而自动生成第二个代理码。
- 数据库增加代理邀请码唯一约束，并在迁移中收敛历史重复记录。
- 后台邀请码页面明确展示固定邀请码，不再把入口描述为可无限创建。
- 保留邀请码启用/停用能力；停用固定码不会自动替换成新码。

## 验收标准

- 同一代理重复请求创建接口返回同一个邀请码和记录。
- 并发初始化最多保留一条代理邀请码。
- 历史重复代理码迁移后只保留一个规范记录，历史使用次数合并。
- 用户端、代理后台和邀请码状态切换不再产生第二个代理码。
- 相关 Rust、Web、迁移和 OpenAPI 回归通过。
